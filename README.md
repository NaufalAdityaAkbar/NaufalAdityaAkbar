### 💫 Tentang Saya
Saya adalah seorang **Fullstack Software Engineer** yang berfokus pada sistem terdistribusi dan efisiensi infrastruktur. Berpengalaman dalam membangun arsitektur sistem dari monolith hingga microservices.

- 🏥 **Portofolio Utama:** Telah sukses membangun Sistem Helpdesk & K3 di **RS Azra Bogor** (Laravel & PostgreSQL).
- 🏗️ **Proyek Berjalan:** Arsitektur **Semi-Microservices** menggunakan **Golang**, **Express.js**, dan **PHP**.
- 🐳 **Infrastructure:** Mengimplementasikan **Docker** untuk standardisasi lingkungan pengembangan dan *deployment*.
- 🎓 **Riset Skripsi:** Implementasi **NLP** untuk klasifikasi data medis menggunakan **Python**.
